# Historical Design Packet Index

The `specs/GH<number>/` directories are retained product and implementation
records. The repo-native packet format has three files:

- `product.md` records the user problem, scope, and acceptance criteria.
- `tech.md` records technical decisions, constraints, and verification design.
- `tasks.md` records the implementation breakdown and completion evidence.

Route labels, status fields, named tools, and checklists inside historical
packets describe the workflow in use when that packet was written. They are not
current execution state, do not create an automatic gate, and must not trigger
loading an external workflow. Current repository instructions, maintainer
review, linked issues and pull requests, and fresh verification are
authoritative.

New substantial work may continue to use this product/technical/tasks shape as
a repository-native design format after an issue is linked. Follow
[`AGENTS.md`](../AGENTS.md) for the current change and design route.
